# To-Do List App ✅

A modern and interactive To-Do List web application built using HTML, CSS, and Vanilla JavaScript. This project allows users to dynamically add tasks, mark tasks as completed, and delete tasks in real time with a clean and responsive UI.

---

## ✨ Features

- Add Tasks Dynamically
- Delete Tasks Individually
- Mark Tasks as Completed
- Scrollable Task List
- Clean and Responsive UI

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript

## 🚀 How It Works

1. User enters a task in the input field.
2. Clicking the "Add Task" button dynamically creates:
   - a task container (`li`)
   - a checkbox
   - task text (`span`)
   - delete button
3. The task is inserted into the task list using DOM manipulation.
4. Users can:
   - mark tasks complete
   - delete tasks individually
